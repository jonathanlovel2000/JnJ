Apa itu ekstensi domain?

Ekstensi domain adalah akhiran (bagian terakhir) dari nama domain yang muncul setelah tanda titik (.) pada alamat website. Contohnya pada alamat www.google.com, bagian “.com” itulah yang disebut ekstensi domain. Ekstensi domain berfungsi untuk: Menunjukkan jenis atau kategori website. Kadang juga menunjukkan asal negara dari website tersebut. Membantu pengunjung mengenali tujuan utama dari situs itu (bisnis, organisasi, pendidikan, dll).

🏷️ Jenis-Jenis Ekstensi Domain

Ekstensi domain dibagi menjadi beberapa jenis utama, yaitu:

1. TLD (Top Level Domain) TLD adalah ekstensi domain tingkat atas yang paling umum digunakan di seluruh dunia. Jenis ini tidak terikat pada negara tertentu. Contoh: .com → digunakan untuk situs komersial atau bisnis. .org → untuk organisasi non-profit atau lembaga sosial. .net → awalnya untuk jaringan (network), kini bisa digunakan umum. .info → untuk situs yang berisi informasi. .biz → untuk kegiatan bisnis. > 💬 Contoh penggunaan: tokopedia.com wikipedia.org netflix.net

2. ccTLD (Country Code Top Level Domain) Ekstensi ini menunjukkan kode negara asal website. Biasanya terdiri dari dua huruf sesuai ISO code negara. Contoh: .id → Indonesia .jp → Jepang .us → Amerika Serikat .uk → Inggris .au → Australia > 💬 Contoh penggunaan: detik.com → (sering juga dipakai dengan .id seperti detik.id) bbc.co.uk → situs berita Inggris abc.net.au → situs media Australia

3. gTLD (Generic Top Level Domain) gTLD adalah versi baru dari TLD yang lebih spesifik dan kreatif, diciptakan untuk memperluas pilihan nama domain. Ekstensi ini menggambarkan bidang atau industri tertentu. Contoh: .tech → untuk situs teknologi .store → untuk toko online .edu → untuk lembaga pendidikan .travel → untuk industri pariwisata .app → untuk situs atau layanan aplikasi > 💬 Contoh penggunaan: android.app shopify.store coursera.edu

4. Subdomain Meskipun bukan ekstensi, subdomain adalah bagian tambahan di depan domain utama yang digunakan untuk memisahkan bagian tertentu dari website. Contoh: blog.example.com → subdomain untuk halaman blog shop.example.com → subdomain untuk toko online
